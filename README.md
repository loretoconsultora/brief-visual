# Brief visual · Loreto Consultora

Formulario visual (colores, tipografías, estilo, formas, imágenes, presencia personal, idioma y aplicaciones) para construir moodboards de marca.

- Página estática: `index.html` (sin dependencias ni build).
- Las respuestas se guardan en el navegador de quien responde y se descargan como PDF desde la pantalla de resumen.
- Prellenar la marca en el link: `?marca=Nombre%20de%20la%20marca`.

Despliegue: importar el repo en Vercel (Framework preset: Other, sin build command).
